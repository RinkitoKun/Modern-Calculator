# 🧮 Multi-Theme Calculator  

Welcome to the **Multi-Theme Calculator** project!  
This fully functional calculator is built using **JavaScript, HTML, and CSS** and offers multiple themes for a personalized experience. It supports both **mouse clicks** and **keyboard input**, making it user-friendly and versatile.  

---

## 🌐 Live Demo  

Check out the live deployment here: [Multi-Theme Calculator](https://rinkitokun.github.io/Modern-Calculator/)  

---

## 🚀 Features  

- **Basic Operations**: Perform addition, subtraction, multiplication, and division with ease.  
- **Multiple Themes**: Choose between light, dark, or custom themes to suit your preferences.  
- **Keyboard Input Support**: Use your keyboard for faster input of numbers and operators.  
- **Responsive Design**: Fully functional on both desktop and mobile devices.  
- **Error Handling**: Graceful error messages for invalid operations (e.g., division by zero).  
- **Clear and Backspace Buttons**: Easily reset calculations or delete the last entered value.  

---

## 🎯 How It Works  

1. **Theme Switching**:  
   - Users can switch themes dynamically using buttons or a toggle switch.  
   - CSS variables update in real-time to apply the selected theme.  

2. **Keyboard Input**:  
   - Detects key presses for numbers, operators, and actions like "Enter" (equals) and "Backspace."  
   - Provides a seamless experience for users who prefer typing.  

3. **Calculation Logic**:  
   - JavaScript handles mathematical operations using a simple and efficient parsing algorithm.  
   - Results are displayed instantly after each calculation.  

---

## 🛠️ Built With  

- **HTML**: To structure the calculator's interface.  
- **CSS**: For styling, animations, and theme management.  
- **JavaScript**: To handle input, operations, and dynamic theme switching.  

---

## 💻 How to Use  

1. Open the calculator in your browser.  
2. Choose your preferred theme using the theme selector.  
3. Perform calculations by:  
   - Clicking buttons on the calculator interface.  
   - Using your keyboard for input (e.g., numbers, operators, "Enter" for equals, and "Backspace" for delete).
